# erdi-lrf (Python)

Python driver and `erdi-lrf` CLI for ERDI 905 nm laser rangefinder modules.

```bash
pip install -e .
erdi-lrf models
erdi-lrf --port COM3 --model LRF3000A1 measure
```

Full documentation, protocol tables and the hardware catalogue are in the
repository root: <https://github.com/yu911517778-a11y/erdi-lrf-drivers>.
